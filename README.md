# SupplyGuardian - Decentralized Supply Chain Verification

A blockchain-based supply chain tracking and verification system built on Stacks, ensuring product authenticity and transparent logistics.

## Features
- Product registration and cataloging
- Real-time shipment tracking
- Third-party certification system
- Immutable audit trails

## Smart Contract Functions
- `register-product`: Add products to supply chain
- `track-shipment`: Record shipment movements
- `certify-product`: Auditor verification
- `get-product`: Retrieve product information
